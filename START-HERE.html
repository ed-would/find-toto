Сначала распакуй весь архив в обычную папку. Затем выбери, как открыть игру:

Проверить все 13 остановокНачать настоящее путешествие
В режиме проверки всё открыто сразу, есть просмотр открыток, а обычное сохранение не меняется. Обычный запуск сразу запоминает время начала в этом браузере: первая остановка доступна сейчас, дальше по одной каждые 30 минут.

Чтобы Рина играла по настоящей ссылке

  1. Создай репозиторий на GitHub и загрузи содержимое этой папки, включая .github/workflows/pages.yml. index.html должен быть в корне репозитория.
  2. Открой Settings → Pages и выбери источник GitHub Actions.
  3. Во вкладке Actions запусти A little birthday magic → Run workflow для main.
  4. Когда публикация завершится, возьми ссылку из Settings → Pages. Проверь её с ?preview=1, а Рине отправь без этого окончания.
